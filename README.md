# Nail Studio · Казань

Сайт мастера маникюра с примерочной: посетитель загружает фото своей руки и примеряет дизайны ногтей (форма, длина, глянец/мат, хром, кошачий глаз, блёстки).

## Как открыть

Откройте `index.html` в браузере или включите GitHub Pages: **Settings → Pages → Deploy from a branch → `main` / root**.

Автопоиск ногтей на фото (нейросеть MediaPipe) подгружается из интернета, поэтому лучше всего работает на опубликованном сайте. Без интернета ногти отмечаются вручную.

## Настройка

Контакты, название и адрес задаются в `js/config.js`.

## Структура

- `index.html` — страница
- `css/style.css` — стили
- `js/nailfx.js` — WebGL-рендер ногтей поверх фото
- `js/designs.js` — каталог дизайнов и форм
- `js/studio.js` — примерочная (загрузка фото, разметка, выбор дизайна)
- `js/detect.js` — автопоиск ногтей (MediaPipe Hand Landmarker)
- `js/models.js` — демо-фото с разметкой ногтей
- `js/gl3d.js`, `js/decor.js` — 3D-декор в первом экране
- `assets/` — фото работ и видео
